# 📚 AI Engineering Books

A curated collection of books and learning resources for **AI Engineering, Machine Learning, Deep Learning, and Large Language Models (LLMs)**.

This repository is created to organize useful technical books that help developers, engineers, and AI enthusiasts build strong foundations and develop practical skills in modern AI engineering.

## 📖 Available Books

| # | Book Title | Category |
|---|---|---|
| 1 | AI Engineering — Chip Huyen | AI Engineering |
| 2 | Building LLMs From Scratch | Large Language Models |
| 3 | Designing Machine Learning Systems | Machine Learning Systems |
| 4 | Hands-On Machine Learning with Scikit-Learn | Machine Learning |
| 5 | LLM Engineer's Handbook — Paul Iusztin & Maxime Labonne | LLM Engineering |

## 🎯 Repository Goals

- Build a curated library of AI and Machine Learning books.
- Learn the fundamentals of modern AI engineering.
- Understand Large Language Models and their architectures.
- Explore practical machine learning techniques.
- Learn how to design, build, and deploy AI-powered applications.
- Support continuous learning and skill development.

## 🧠 Topics Covered

- Artificial Intelligence (AI)
- Machine Learning (ML)

- Large Language Models (LLMs)

- AI System Design
- MLOps and Deployment
- AI Engineering Best Practices

## 🚀 Who Is This Repository For?

This repository is useful for:

- Beginners exploring Generative AI.
